# git-save: сохранить блок работы

Ритуал из `project-starter.md`, раздел 6. Выполняй шаги по порядку. Команды для **PowerShell**, из корня проекта (`C:\claude_code_projects\sobes_voice`). Если пользователь передал аргумент, это тема коммита.

## 1. Осмотр
`git status --short` и `git diff --stat`. Если изменений нет, скажи об этом и остановись.

## 2. Проверки (до любых правок документов)
- `.\.venv\Scripts\python.exe -m pytest -q` — все тесты зелёные.
- `pyright` — `0 errors`.

Если что-то красное: покажи вывод, **не коммить**, спроси, что делать.

## 3. Проверка на утечки
В `git status` не должно быть `data/`, `.env`, `*.wav`, `*.onnx`, `*.pt`, `.venv/`. Просмотри diff на токены, ключи, пароли, личные данные (резюме, кейсы, расшифровки). При сомнении остановись и спроси.

## 4. Контекстные файлы: обновить ВСЕ ТРИ
Ни один не пропускай на том основании, что «уже записано в другом». Это разные документы. Правь точечно через Edit, не перезаписывай файлы целиком, ручные правки пользователя не затирай.

- **MEMORY.md**: новая запись сверху раздела «Лог сессий» (дата, тема, что сделано, решения, замеры, найденные проблемы); обновить «Статус проекта» и «Открытые вопросы». Прошлое не переписывать.
- **ARCHITECTURE.md**: запись в «Changelog»; сверить «Структура», «Команды», «Отклонения от PLAN.md» с реальным состоянием проекта. Если файл не обновлялся 2 сохранения подряд, сделай полную сверку разделов, а не одну строку changelog.
- **README.md**: проверь разделы, которых коснулись изменения (запуск, стек, структура, команды). Если менять нечего, так и скажи в отчёте, но проверить обязательно.

## 5. Коммит
- `git add -A`.
- Сообщение на английском, короткая тема, при необходимости пустая строка и пояснение. Многострочное сообщение пиши в файл `.commitmsg.tmp`, затем `git commit -F .commitmsg.tmp` и удали файл.
- В конце сообщения строка `Co-Authored-By`, заданная в инструкциях сессии.

## 6. Пуш
`git push`. Никаких `--force`, `--amend`, `--no-verify`.

## 7. Отчёт
Коротко: хеш коммита, какие файлы документации обновлены (и что README не требовал правок, если так), итог pytest и pyright, что остаётся открытым.
