# Interview Trainer

Локальный голосовой тренажёр собеседований на русском языке. Вопросы озвучиваются, ответ записывается с микрофона, распознаётся и разбирается локальной LLM. Облачные API не используются.

> Статус: в разработке. Готовы этапы 0–1 (голосовой цикл), 2 (собеседования, документы, список вопросов, сохранение на диск), 3 (качество фидбека: профиль кандидата, эталонные ответы, проверка цитат) и 4 (генерация вопросов из вакансии и профиля; ждёт вашей проверки). Дальше: итоговый отчёт и история (этап 5). Нарядная версия README со схемами и объяснением решений появится на этапе 6.

## Как это работает
Вопрос озвучивается (Silero TTS), ответ записывается в браузере и распознаётся (GigaAM, CPU), затем Qwen в LM Studio разбирает ответ и даёт фидбек текстом и голосом.

## Стек
Python 3.11, FastAPI, onnx-asr (GigaAM v3), Silero TTS, LM Studio (Qwen), чистый HTML/JS/CSS.

## Быстрый старт (Windows, PowerShell)
1. Запустите LM Studio, загрузите Qwen (Q4_K_M, контекст 8192) и включите Local Server на порту 1234.
2. Один раз: `py -3.11 -m venv .venv`, затем `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
3. Запуск: `.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`, затем откройте `http://localhost:8000`.
4. В браузере: создайте собеседование, загрузите файл с вопросами (md, txt, docx или pdf), резюме и вакансию (или вставьте текст через «Вставить текст»), нажмите «Собрать профиль» (проверьте факты), «Извлечь вопросы», при желании включите «Догенерировать вопросы из вакансии и профиля» (по умолчанию вопросы берутся только из файла, сгенерированные добавятся к списку), поправьте список, «Утвердить список», «Начать собеседование». Если в файле вопросов под вопросом есть блок «Коротко:», он станет эталонным ответом. Данные сохраняются в `data/` (личные, в git не попадают).
5. Качество разбора ответов: `.\.venv\Scripts\python.exe scripts\eval_review.py` (нужен LM Studio).
6. Тесты: `.\.venv\Scripts\python.exe -m pytest -q`; типы: `pyright`.
