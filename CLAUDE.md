# CLAUDE.md — Interview Trainer (локальный голосовой тренажёр собеседований)

Полный план работ: **PLAN.md**. Читай его перед каждым этапом.

## Контекст
- Пользователь: продуктовый аналитик, тренирует собеседования на русском языке.
- Приложение полностью локальное. Никаких облачных API.
- Железо: Windows 10/11, NVIDIA RTX 3060 12 GB. LLM крутится в LM Studio.
- Видеопамять почти целиком отдана LLM. STT и TTS работают на **CPU**.

## Правила работы
1. Работай **строго по этапам из PLAN.md**, по одному за раз. В конце этапа остановись и сообщи:
   - что сделано;
   - как проверить: точные команды PowerShell и что нажать в браузере;
   - что осталось открытым.
   Следующий этап начинай только после подтверждения пользователя.
2. ОС Windows. Команды пиши для **PowerShell**. Пути строй через `pathlib`, без жёстких `/`.
3. Python 3.11, виртуальное окружение `.venv`. Зависимости с закреплёнными версиями в `requirements.txt`.
4. **torch ставь CPU-сборку** (`--index-url https://download.pytorch.org/whl/cpu`). CUDA-сборку только по явной просьбе.
5. Перед скачиванием файлов больше 1 GB или установкой системных компонентов спроси разрешения.
6. LLM вызывай только через OpenAI-совместимый сервер LM Studio (`http://localhost:1234/v1`) клиентом `openai`. Адрес и модель берутся из `config.yaml`.
7. Интерфейс, промпты и сообщения об ошибках на русском. Имена в коде на английском.
8. Папка `data/` (резюме, кейсы, записи, отчёты) — личные данные. Она в `.gitignore` и не попадает в git.
9. Тесты на `pytest`. LLM, STT и TTS в юнит-тестах мокаются. Реальные проверки моделей вынесены в `scripts/check_*.py`.
10. Не усложняй: без БД (только JSON-файлы), без фронтенд-фреймворков (чистый HTML/JS/CSS), без авторизации, один пользователь.
11. API конкретных библиотек (onnx-asr, silero, LM Studio structured output) сверяй с их актуальной документацией. Если что-то из PLAN.md не работает как описано, сообщи и предложи замену, не выкручивайся молча.
